# 🍱 HomeTiffin – Home Tiffin Service Website

HomeTiffin is a simple and user-friendly home tiffin service website built using **HTML, CSS, and JavaScript**. It provides a platform where users can explore food menus, manage their cart, place orders, and track their orders.

## 🚀 Features

- 🏠 Home Page – Introduction to the home tiffin service.
- 🔐 Authentication Page – User login and authentication interface.
- 🍽️ Menu Page – Explore available food items.
- 🛒 Shopping Cart – Manage selected food items.
- 📦 Orders Page – View order information.
- 🚚 Order Tracking – Track order status.
- 📞 Contact Page – Contact information and support.
- 📱 Responsive Design – User-friendly interface across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js & npm (for project testing and dependency management)

## 💻 How to Run the Project

**1. Clone the repository**

```bash
git clone https://github.com/VaruRoshani/HomeTiffin.git
```

**2. Open the project folder**

```bash
cd HomeTiffin
```

**3. Install dependencies**

```bash
npm install
```

**4. Run the project**

Open `index.html` in your browser or use the Live Server extension in VS Code.

## 🧪 Run Tests

Run the following command in the terminal:

```bash
npm test
```
